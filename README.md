# Adventure Works Power BI Report

📊 A professional business intelligence dashboard built using the classic **Adventure Works** dataset.

## 🔍 Key Features
- Sales performance by product category, region, and date
- Profitability trends and gross margin analysis
- Year-over-year sales comparisons
- Interactive visuals with slicers and drill-downs

## 🧰 Tools & Technologies
- Microsoft Power BI
- DAX Measures
- Data Modeling (Star Schema)
- Time Intelligence functions

## 🎯 Purpose
To demonstrate advanced Power BI capabilities using a structured sales and marketing dataset. Ideal for showcasing sales analysis, business performance, and data storytelling.
